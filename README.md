# Senior Activities / Life Nearby

Prototype for helping older adults, families and caregivers find suitable nearby activities.

## Validation milestone
Structure 50 current Vaughan/York Region activities and test whether five caregivers can find an appropriate option in under two minutes.

## Product principle
Do not build another generic directory. Help answer: **What can Mom or Dad realistically do this week?**

The current site uses clearly labelled sample data while the verified activity dataset is assembled.
